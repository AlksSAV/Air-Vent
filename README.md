# Air-Vent — Контроллер осушения подвала

Микроконтроллер на базе Arduino Uno для автоматического управления вентиляцией подвала с целью осушения воздуха.

## 📦 Аппаратная часть

| Компонент | Кол-во | Примечание |
|-----------|--------|------------|
| Arduino Uno (ATmega328P) | 1 | |
| Датчик DHT22 | 2 | Один наружный, один внутренний |
| LCD 1602 (без I2C) | 1 | Подключён напрямую через D4–D9 |
| LCD Keypad Shield | 1 | Клавиши: Select, Up, Down, Left, Right |
| Реле вентилятора | 1 | Активный уровень HIGH (через оптопару/транзистор) |

### Назначение пинов

| Пин Uno | Функция |
|---------|---------|
| D2 | TX (отладка через Serial) |
| D3 | Реле вентилятора |
| D4–D9 | LCD 1602 (RS, EN, D4–D7) |
| D10 | Подсветка LCD Keypad Shield |
| A0 | Клавиатура щита (АЦП) |
| A1 | DHT22 наружный |
| A2 | DHT22 внутренний |

## 🧠 Принцип работы

### Алгоритм осушения

Вентилятор включается, когда **абсолютная влажность наружного воздуха меньше внутренней** — приточный воздух осушает подвал.

### Защита от конденсата

Если **точка росы наружного воздуха выше температуры внутреннего**, вентилятор не включается. Холодный влажный воздух при контакте с тёплыми стенами мгновенно создаст конденсат, сводя весь смысл осушения на нет.

### Гистерезис

Чтобы вентилятор не циклился на одном значении влажности, используется два порога:

- **Включение**: разница абсолютной влажности `внутри − снаружи > 2.0 г/м³`
- **Выключение**: разница упала `< 0.5 г/м³`

### Ограничения по температуре

Вентилятор работает только если наружная температура в пределах:
- `Tmin` (нижний предел, настраивается)
- `Tmax` (верхний предел, настраивается)

По умолчанию: `7 °C … 40 °C`.

### Лимит непрерывной работы

- **30 минут** включён → **15 минут** пауза
- Защита от переохлаждения подвала.

### Защита по устареванию данных

Если ни один датчик не отвечает **10 минут** — вентилятор принудительно выключается.

### Принудительная вентиляция

Ручной режим для быстрого проветривания, удаления запаха или проверки вентилятора. В этом режиме реле держится включённым, а алгоритм осушения и все его ограничители (влажность, температурный коридор, лимит непрерывной работы, достоверность данных) игнорируются.

- **Включить**: двойное нажатие **Up**
- **Выключить**: одинарное нажатие **Up**
- Ограничения по времени нет — режим снимается только кнопкой
- Наработка вентилятора в EEPROM продолжается как обычно
- В EEPROM не сохраняется: после перезагрузки контроллер стартует в штатном режиме

## 📺 Дисплей

LCD 1602 показывает три экрана (переключение клавишами Left/Right):

| Экран | Содержимое |
|-------|------------|
| **Климат** | `OUT +20C 50%` / `IN +15C 60%` |
| **Абс. влажность** | `Out 8.6 Td 9.3` / `In 10.2 d+1.6` |
| **Статус** | `FAN ON   04h32` / `Tmin+ 7 Tmax+40` |

В принудительном режиме на экране статуса вместо `FAN ON` показывается `FORCE ON`. При отказе датчика в этом режиме экран показывает `FORCE ON` и `sensor error too` — работающий вентилятор не должен прятаться за сообщением об ошибке.

### Управление

| Клавиша | Обычный режим | Режим настроек |
|---------|---------------|----------------|
| **Select** | вход в настройки | сохранить и выйти |
| **Up** | двойное — FORCE вкл, одинарное — FORCE выкл | увеличить уставку |
| **Down** | — | уменьшить уставку |
| **Left** | следующий экран | выбрать параметр (Tmin / Tmax) |
| **Right** | следующий экран | — |

### Режим настроек

Нажмите **Select** для входа:
- **Up** — увеличить выбранную уставку
- **Down** — уменьшить
- **Left** — переключить параметр (Tmin / Tmax)
- **Select** — сохранить и выйти (или через 30 секунд бездействия)

Одиночное и двойное нажатие различаются по окну в 400 мс, поэтому отклик одинарного нажатия Up на выключение FORCE приходит с такой задержкой.

## 🔧 Сборка и прошивка

### Требования

- [PlatformIO Core](https://docs.platformio.org/) (6.2+)
- Arduino IDE не требуется

### Команды

```bash
# Скачать зависимости и собрать
pio run

# Прошить Arduino Uno (через USB)
pio run -t upload

# Открыть монитор порта (отладочная телеметрия)
pio device monitor

# Очистить и собрать заново
pio run -t clean && pio run
```

|------------|------------|
| LiquidCrystal 1.0.7 | LCD 1602 |
| DHT sensor 1.4.6 | Датчики DHT22 |
| Adafruit Unified Sensor | Базовый класс для DHT |

## 📊 Формулы

### Абсолютная влажность (г/м³)

Давление насыщенного пара — уравнение Магнуса-Альдуха-Эспенса:

```
es = 6.1094 × exp(17.625 × T / (243.04 + T))   [гПа]
e  = es × RH / 100                                [гПа]
ρ  = e × 100 / (R × (T + 273.15)) × 1000        [г/м³]
```

где `R = 461.5 Дж/(кг·К)` — удельная газовая постоянная водяного пара.

### Точка росы

```
Td = B × γ / (A − γ)
γ  = ln(RH/100) + A×T/(B+T)
A = 17.625, B = 243.04
```

## 📝 EEPROM

| Адрес | Размер | Описание |
|-------|--------|----------|
| 0 | 1 байт | Магическое число `0x66` (102) |
| 1 | 2 байта | `t_min` (int16, big-endian) |
| 3 | 2 байта | `t_max` (int16, big-endian) |
| 5 | 4 байта | Накопленные часы работы вентилятора (uint32) |

Ресурс EEPROM — ~100 000 циклов записи. Запись `t_min`/`t_max` происходит только при выходе из режима настроек. Запись часов работы — не чаще раза в час.

## 🛡️ Безопасность

- При прошивке отключите питание вентилятора (реле на D3)
- Используйте оптопару или реле с гальванической развязкой
- DHT22 работает от 3.3В–5В, не подавайте более 5.5В
